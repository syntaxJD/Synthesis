# Discover Accra - City Travel Guide

A 4-page responsive travel guide web app built with HTML, CSS and JavaScript.

## Features
- Semantic HTML5 layout, accessible forms, skip link
- Destinations loaded with Ajax (`fetch`) from `data/destinations.json`, with built-in fallback
- Filter, search and save favourites (localStorage)
- Itinerary table with `rowspan`/`colspan`, nested lists and show/hide details
- Trip budget calculator and validated form
- Mobile-first responsive CSS, dark mode toggle

## Run locally (XAMPP)
1. Copy this folder to `C:\xampp\htdocs\travel-guide`
2. Start Apache in the XAMPP Control Panel
3. Open http://localhost/travel-guide/

No PHP or database needed.
